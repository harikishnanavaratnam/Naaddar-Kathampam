# Editor guide — Naaddaar Kathampam

A one-page guide for committee members who update the website. No coding needed.

## Logging in

Open the Studio link you were given (looks like `https://naaddaarkathampam.sanity.studio`) and sign in with your invited email.

## The golden rule

Every text box comes in **two languages — தமிழ் (Tamil) first, then English**. Fill **both**. When you're done editing something, click **Publish** (top of the screen). The website updates itself in about 1–2 minutes.

## Common tasks

**Add a news post** → *News → Create new* → fill title, body (Tamil + English), date, category, optional image → **Publish**.

**Set this year's event** → *Events → Create new* (or open the current one) → fill date, venue, description, upload the poster/PDF → turn on **"Current event?"** → **Publish**. (Only one event should be "current".)

**Add the programme** → inside that event, add **Programme rows** (time, item, performer, stage) and drag to reorder.

**Add / reorder committee, sponsors, gallery, timeline** → open that list → *Create new*, or **drag** items to reorder → **Publish**.

**Gallery videos** → paste a **YouTube URL** instead of uploading a video file (keeps the site fast).

## Please don't touch

Project **Settings**, **datasets**, or the schema. If something looks wrong there, tell the site admin. (Editors have full access on our plan, so this matters.)

## If you remove something

Deleting or unpublishing a post/member also updates the live site automatically — no extra step.
